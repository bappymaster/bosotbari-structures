# ভিডিও প্ল্যান সপ্তাহ ১ — ৭টি রিল (৪৫–৯০ সেকেন্ড, 1080×1920)

সব ভিডিওর নিয়ম:
- অডিও: মিনহাজের আসল রেকর্ডিং থেকে কাট (source/ep01_minhaz.opus), নয়েজ ক্লিন, 48 kHz স্টেরিও (FB সাইলেন্ট বাগ এড়াতে)।
- প্রথম ৩ সেকেন্ড: সবচেয়ে চমকে দেওয়া লাইন + সবচেয়ে চমকে দেওয়া ভিজুয়াল।
- ভিজুয়াল: Flow/Gemini দিয়ে ৪–৬টা স্টিল + হালকা মোশন (zoom/pan নয়, 2D কাট-আউট প্যারালাক্স বা Three.js ক্যামেরা), ব্যাজ উপরে-বামে, ভিডিওর গায়ে ক্যাপশন নয় (ভয়েস বহন করবে), শুধু বড় সংখ্যা ২–৩ বার।
- শেষ ৩ সেকেন্ড: "প্রশ্ন থাকলে কমেন্টে, বা ওয়েবসাইটে" + ব্যাজ।
- পোস্ট: FB রিল ১৭:০০ BST, একই ফাইল YouTube Shorts + TikTok। টাইটেল + ডেসক্রিপশন দুটোই।

## প্রতিটি ভিডিওর প্রোডাকশন চেকলিস্ট
1. অডিও সেগমেন্ট কাট (ffmpeg -ss/-to), 48 kHz, লাউডনেস -16 LUFS
2. ৫টি Flow ইমেজ (প্রম্পট week1.md-র স্টাইলে, 9:16)
3. 08_TOOLS রেন্ডারার দিয়ে MP4 (ব্যাজ উপরে-বামে x40 y40)
4. থাম্বনেইল/কভার: প্রথম ফ্রেম = পে-অফ, ২–৫ শব্দের প্রশ্ন, সাবটাইটেল ছোট
5. মিনহাজ ✅ (তথ্য) + বাপ্পী ✅ (কভার)
6. আপলোড FB রিল + YT Shorts + TikTok, টাইটেল+ডেসক্রিপশন, ক্রেডিট প্রথম কমেন্টে
7. ট্র্যাকারে লিংক + রিচ লিখে রাখা
